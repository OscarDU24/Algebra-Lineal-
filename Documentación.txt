# Estructuración Inicial del Backend (18/08/2026 hasta 25/08/2026)

Tomando en cuenta las indicaciones provistas por el docente, se estructuró un programa
que puede realizar las siguientes funciones:

1. Establecer el tamaño de una matriz en base a n:m n x m.
2. Poder Consultar los valores que se encuentran en una posición específica de la matriz.
3. Mostrar La matriz completa.
4. Realizar operaciones elementales de matrices.
5. Validadores que impiden el fallo del programa.

Cosas a mejorar tomando en cuenta las orientaciones dadas el 25/08/2026

1. Él sistema de hacer automáticamente las operaciones elementales
2. Cuando se hagan dichas operaciones el usuario debe decidir si llega hasta Gauss o Gauss-Jordan
3. Evitar usar Librerías NumPy, SciPy o funciones integradas de álgebra lineal de math.
4. El programa debe construirse utilizando únicamente Python estándar (listas anidadas, condicionales if/else, bucles for/while y funciones). 
5. Agregar comentarios al código.

# Reformas para el merge (26/08/2026 hasta 28/08/2026)

1. Tomando en cuenta las nuevas orientaciones provistas por el docente, se comenzó a reestructurar el programa para adaptarlo a la resolución de sistemas de ecuaciones lineales mediante métodos matriciales. Se modificó el funcionamiento de la matriz para que pueda representar una matriz aumentada A|b, donde se almacenan los coeficientes de las variables y los términos independientes de cada ecuación.

2. Se estableció que el usuario pueda indicar desde la consola el número de ecuaciones y el número de variables que tendrá el sistema, permitiendo trabajar con diferentes tamaños de matrices.Se modificó el ingreso de valores para que el programa acepte tanto números enteros como números decimales en los coeficientes y términos independientes.

3. Se planteó la incorporación de un proceso automático de eliminación por filas, con el objetivo de que el programa pueda realizar las operaciones necesarias para resolver el sistema sin que el usuario tenga que realizarlas manualmente.

4. También se incorporó la clasificación del sistema dependiendo del resultado obtenido, permitiendo identificar si presenta una solución única, infinitas soluciones o si no presenta solución.

5. El programa deberá mostrar la matriz aumentada inicial y los cambios realizados durante el proceso de eliminación, permitiendo observar de manera ordenada los pasos utilizados para resolver el sistema. Se agregó como parte del proceso la obtención de los valores de las variables cuando el sistema presente una solución única.

6. También se planteó una etapa de verificación, en la cual los valores obtenidos serán sustituidos en el sistema original para comprobar automáticamente que la solución encontrada sea correcta. La estructura del proyecto continúa organizada mediante los paquetes Models, Dao y Menus, agregando el paquete Services para separar la lógica correspondiente al proceso de eliminación y resolución de los sistemas.

7. Se mantiene la restricción de no utilizar las librerías NumPy, SciPy ni funciones integradas de álgebra lineal, utilizando únicamente las herramientas estándar de Python, como listas anidadas, condicionales, ciclos y funciones. Finalmente, se deberán realizar pruebas con los tres casos solicitados por el docente: un sistema con solución única, un sistema con infinitas soluciones y un sistema inconsistente o sin solución.
