2. visualizacion.py
2.1 copiar_matriz(matriz)
def copiar_matriz(matriz):
    return [fila[:] for fila in matriz]
Esto es una comprension de lista: recorre cada fila dentro de matriz y para cada una hace fila[:], que crea una copia nueva de esa fila (no la misma referencia en memoria). Es necesario porque en Python, si haces nueva = matriz sin esto, nueva y matriz apuntarian al mismo objeto, y modificar una modificaria la otra sin querer.

def imprimir_matriz(matriz, titulo=""):

3.1 eliminacion_por_filas(matriz_original, modo)
def eliminacion_por_filas(matriz_original, modo="gauss"):
    matriz = copiar_matriz(matriz_original)
Trabaja sobre una copia, nunca sobre matriz_original directamente, para no alterar la matriz que el usuario ingreso (se necesitara intacta despues, en la verificacion).
    filas = len(matriz)
    columnas = len(matriz[0])
    variables = columnas - 1
Guarda cuantas filas (m) y columnas totales tiene. variables es n: las columnas menos 1 (se resta la columna del termino independiente).
    pasos = [("Matriz aumentada inicial", copiar_matriz(matriz))]
Crea una lista pasos que arranca con una tupla: (descripcion del paso, una copia de la matriz en ese momento). Esto es lo que luego permite mostrarle al usuario el proceso completo.
    columnas_pivote = []
    fila_pivote = 0
columnas_pivote guardara que columnas lograron tener un pivote. fila_pivote es un contador que indica en que fila estamos posicionados para poner el proximo pivote (empieza en la fila 0).
    for col in range(variables):
        if fila_pivote >= filas:
            break
Recorre columna por columna (cada columna representa una variable). Si ya no quedan filas disponibles para poner mas pivotes (fila_pivote llego al total de filas), corta el bucle: ya no se puede seguir.
        fila_max = fila_pivote
        for r in range(fila_pivote + 1, filas):
            if abs(matriz[r][col]) > abs(matriz[fila_max][col]):
                fila_max = r
Esto es el pivoteo parcial: empieza asumiendo que la fila actual (fila_pivote) tiene el mejor candidato, y recorre las filas de abajo comparando valores absolutos. Si encuentra uno mayor, actualiza fila_max a esa fila. Al terminar el bucle, fila_max es la fila con el coeficiente mas grande (en valor absoluto) de esa columna, entre las filas restantes.
        if abs(matriz[fila_max][col]) < TOLERANCIA:
            continue
Si ni el mejor candidato supera la tolerancia, esa columna no tiene ningun valor util como pivote (toda esa columna, desde fila_pivote hacia abajo, es practicamente cero). continue salta directamente a la siguiente columna, sin tocar fila_pivote ni columnas_pivote; esta es la variable que queda "libre".
        if fila_max != fila_pivote:
            matriz[fila_pivote], matriz[fila_max] = matriz[fila_max], matriz[fila_pivote]
Si el mejor candidato no es la fila donde ya estamos posicionados, intercambia ambas filas completas. Esta es la sintaxis de Python para intercambiar dos variables sin necesitar una variable temporal.
            pasos.append((
                f"Intercambio de fila {fila_pivote + 1} con fila {fila_max + 1}",
                copiar_matriz(matriz)
            ))
Registra ese intercambio como un paso mas, guardando una copia del estado actual de la matriz.
        if modo == "gauss_jordan":
A partir de aqui se bifurca el comportamiento segun el metodo elegido.
            valor_pivote = matriz[fila_pivote][col]
            for c in range(col, columnas):
                matriz[fila_pivote][c] /= valor_pivote
(Solo Gauss-Jordan) Guarda el valor del pivote, y divide toda la fila pivote (desde la columna actual en adelante) entre ese valor. Esto hace que el pivote mismo quede en exactamente 1. Empieza en col, no en 0, porque las columnas anteriores a col ya son cero en esta fila (no hace falta tocarlas).
            pasos.append((
                f"F{fila_pivote + 1} = F{fila_pivote + 1} / {valor_pivote:.4f}",
                copiar_matriz(matriz)
            ))
Registra ese paso con una descripcion tipo "F1 = F1 / 2.0000".
            for r in range(filas):
                if r != fila_pivote and abs(matriz[r][col]) > TOLERANCIA:
(Sigue en Gauss-Jordan) Recorre todas las filas (range(filas), no solo las de abajo), salvo la fila pivote misma, y solo actua si esa fila todavia tiene un valor distinto de cero en la columna actual (si ya es cero, no hay nada que hacer, evita trabajo innecesario).
                    factor = matriz[r][col]
                    for c in range(col, columnas):
                        matriz[r][c] -= factor * matriz[fila_pivote][c]
factor es el valor a eliminar. Como la fila pivote ya tiene un 1 en la columna col (por la normalizacion de arriba), restar factor veces la fila pivote hace que esa posicion quede en cero. Esto se aplica a toda la fila, desde col en adelante.
                    pasos.append((
                        f"F{r + 1} = F{r + 1} - ({factor:.4f}) * F{fila_pivote + 1}",
                        copiar_matriz(matriz)
                    ))
Registra el paso de eliminacion con su descripcion algebraica.
        else:
            for r in range(fila_pivote + 1, filas):
                if abs(matriz[r][col]) > TOLERANCIA:
(Solo Gauss, rama else) Aqui solo recorre las filas debajo del pivote (fila_pivote + 1 en adelante); a diferencia de Gauss-Jordan, nunca toca las filas de arriba.
                    factor = matriz[r][col] / matriz[fila_pivote][col]
Aqui si hace falta dividir explicitamente entre matriz[fila_pivote][col], porque a diferencia de Gauss-Jordan, el pivote no fue normalizado a 1 en este modo.
                    for c in range(col, columnas):
                        matriz[r][c] -= factor * matriz[fila_pivote][c]
                    pasos.append((
                        f"F{r + 1} = F{r + 1} - ({factor:.4f}) * F{fila_pivote + 1}",
                        copiar_matriz(matriz)
                    ))
Misma mecanica de eliminacion y registro de paso que antes.
        columnas_pivote.append(col)
        fila_pivote += 1
Al terminar de procesar la columna (haya sido Gauss o Gauss-Jordan), se registra que esa columna si obtuvo un pivote, y se avanza el contador de fila para la proxima columna.
    return matriz, pasos, columnas_pivote
Al terminar de recorrer todas las columnas, devuelve tres cosas: la matriz ya transformada, el historial completo de pasos, y la lista de que columnas tuvieron pivote.

4.1 clasificar_sistema(matriz_resultado, columnas_pivote)
def clasificar_sistema(matriz_resultado, columnas_pivote):
    filas = len(matriz_resultado)
    columnas = len(matriz_resultado[0])
    variables = columnas - 1
    rango = len(columnas_pivote)
rango es simplemente cuantas columnas lograron tener pivote; este es el concepto de "rango de la matriz" en algebra lineal, expresado en codigo.
    for i in range(filas):
        coeficientes_nulos = all(abs(matriz_resultado[i][j]) < TOLERANCIA for j in range(variables))
all(...) devuelve True solo si todos los elementos cumplen la condicion. Aqui revisa, fila por fila, si todos los coeficientes (todas las columnas excepto la ultima) son practicamente cero.
        termino_no_nulo = abs(matriz_resultado[i][-1]) > TOLERANCIA
Revisa si el termino independiente de esa misma fila no es cero.
        if coeficientes_nulos and termino_no_nulo:
            return "Sistema Inconsistente"
Si ambas cosas son ciertas a la vez (fila tipo 0 0 ... 0 | k con k distinto de cero), eso matematicamente significa "0 = k", una contradiccion. El sistema no tiene solucion, y la funcion termina ahi devolviendo ese resultado.
    if rango == variables:
        return "Sistema Consistente Determinado"
    return "Sistema Consistente Indeterminado"
Si ninguna fila fue contradictoria, se compara el rango contra el numero de variables: si son iguales, hay una unica solucion; si el rango es menor, sobran variables libres (infinitas soluciones).
5. solucion.py
5.1 sustitucion_hacia_atras(matriz_ref, n)
def sustitucion_hacia_atras(matriz_ref, n):
    x = [0.0] * n
Crea una lista de n ceros: el espacio donde se iran guardando los valores de x1, x2, ..., xn (empezando en 0.0 como marcador, luego se sobrescribe cada posicion).
    for i in range(n - 1, -1, -1):
range(n-1, -1, -1) cuenta hacia atras: desde n-1 hasta 0. Es decir, recorre las filas/variables de la ultima a la primera; de ahi el nombre "hacia atras".
        suma = matriz_ref[i][n]
Empieza con el termino independiente de esa fila (la columna n es justo la del termino independiente, ya que hay n columnas de coeficientes indexadas de 0 a n-1).
        for j in range(i + 1, n):
            suma -= matriz_ref[i][j] * x[j]
Resta la contribucion de las variables que ya se calcularon (las que estan a la derecha de la diagonal, con indice mayor a i), multiplicadas por su coeficiente en esta fila.
        x[i] = suma / matriz_ref[i][i]
Despeja la variable actual dividiendo lo que quedo entre su propio coeficiente (el de la diagonal).
    return x
Al terminar de recorrer todas las filas de abajo hacia arriba, devuelve la lista completa de soluciones.
5.2 extraer_solucion_rref(matriz_rref, n)
def extraer_solucion_rref(matriz_rref, n):
    return [matriz_rref[i][n] for i in range(n)]
Como en Gauss-Jordan la matriz ya quedo en forma reducida (identidad a la izquierda), no hace falta ningun calculo: cada xi es simplemente el valor que quedo en la columna del termino independiente (columna n) de la fila i. Esta comprension de lista simplemente recolecta esos n valores.

6.1 verificar_solucion(matriz_original, solucion, tolerancia_verificacion)
def verificar_solucion(matriz_original, solucion, tolerancia_verificacion=1e-5):
Nota la tolerancia distinta (1e-5) por defecto, mas permisiva que la de eliminacion, por la acumulacion de errores de redondeo en la solucion ya calculada.
    filas = len(matriz_original)
    variables = len(solucion)
Cuenta filas del sistema original y cuantas variables hay (largo de la lista solucion).
    for i in range(filas):
        suma = 0.0
        for j in range(variables):
            suma += matriz_original[i][j] * solucion[j]
Para cada ecuacion original, calcula el lado izquierdo sustituyendo los valores encontrados: a1*x1 + a2*x2 + ... + an*xn.
        independiente = matriz_original[i][-1]
        if abs(suma - independiente) > tolerancia_verificacion:
            return False
Compara ese resultado contra el termino independiente real de la ecuacion. Si la diferencia es mayor a la tolerancia permitida, la solucion no cuadra con esa ecuacion, y devuelve False inmediatamente (sin seguir revisando las demas).
    return True
Si paso por todas las ecuaciones sin fallar ninguna, confirma que la solucion es valida.
